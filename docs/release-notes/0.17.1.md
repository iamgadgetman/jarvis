**Security fix — please update.**

In 0.17.0 and earlier, any player could get Jarvis to run admin actions just by asking, console commands included. Now every action Jarvis takes on the server (console commands, giving items, heal/feed, game mode, time, weather, teleports, announcements and the rest) needs `jarvis.admin` (op by default).

To let a group keep one action, grant its node, e.g. `jarvis.admin.actions.heal`. Anyone can still ask Jarvis to request an item from staff. On Fabric and NeoForge these actions need op.
