## 🔧 **Critical Fixes**

### 1. Fix Bedrock Mining (FINAL FIX)
**Problem:** Still mines to bedrock because limit is relative to current position

**Root Cause:**
```java
// CURRENT (BROKEN):
if (b.getY() < center.getY() - 10) continue;
// As Jarvis descends, center.getY() descends, limit descends!
```

**Solution:**
```java
// Track starting Y when mining begins
state.startingY = npcLoc.getY();

// Check against STARTING Y, not current
if (b.getY() < state.startingY - 10) continue;

// Also add hard bedrock limit
if (b.getY() < 10) continue; // Never below Y=10
```

**Additional Safety:**
- Check current Y every tick
- If below startingY - 15, force return to surface
- Alert player: "Too deep! Returning to surface"

### 2. Stop Command

**Implementation:**

```java
    }
}
```

## ⭐ **Feature 1: Vein Mining**

### Overview
When Jarvis finds an ore, detect and mine the entire connected vein.

### Implementation

#### 1. Vein Detection Method
```java
private Set<Block> detectVein(Block startOre, Material oreType) {
    Set<Block> vein = new HashSet<>();
    Queue<Block> toCheck = new LinkedList<>();
    toCheck.add(startOre);
    
    while (!toCheck.isEmpty() && vein.size() < 64) { // Max 64 blocks
        Block current = toCheck.poll();
        
        if (vein.contains(current)) continue;
        if (current.getType() != oreType) continue;
        
        vein.add(current);
        
        // Check all 6 adjacent blocks
        for (BlockFace face : BlockFace.values()) {
            if (face.isCartesian()) {
                toCheck.add(current.getRelative(face));
            }
        }
    }
    
    return vein;
}
```

#### 2. Update Mining Logic
```java
// When ore found:
if (state.targetOre == null) {
    Block ore = findBestOre(npcLoc);
    if (ore != null) {
        // Detect entire vein
        state.currentVein = detectVein(ore, ore.getType());
        state.targetOre = ore;
        
        // Notify player
        player.sendMessage(ChatColor.GREEN + "Jarvis: Found " + 
            ore.getType().name() + " vein (" + state.currentVein.size() + " blocks)");
    }
}

// Mine vein systematically
if (!state.currentVein.isEmpty()) {
    // Get next ore in vein
    state.targetOre = state.currentVein.iterator().next();
}

// After mining ore:
state.currentVein.remove(state.targetOre);
```

## ⭐ **Feature 3: Auto-Return When Full**

### Implementation
```java
private boolean shouldReturnForDropoff(NPC npc, Player player) {
    Inventory inv = npc.getOrAddTrait(Inventory.class);
    ItemStack[] contents = inv.getContents();
    
    int filledSlots = 0;
    int totalSlots = contents.length;
    
    for (ItemStack item : contents) {
        if (item != null && item.getType() != Material.AIR) {
            filledSlots++;
        }
    }
    
    double fillPercent = (filledSlots / (double) totalSlots) * 100;
    
    // Get threshold from config (default 90%)
    int threshold = plugin.getConfig().getInt("mining.auto-return-threshold", 90);
    
    return fillPercent >= threshold;
}

// In mining loop:
if (shouldReturnForDropoff(npc, player)) {
    player.sendMessage(ChatColor.AQUA + "Jarvis: Inventory " + fillPercent + "% full! Returning");
    returnAndDropOff(npc, player, state);
    return;
}

private void returnAndDropOff(NPC npc, Player player, MiningState state) {
    // Save current state
    Block pausedOre = state.targetOre;
    Set<Block> pausedVein = new HashSet<>(state.currentVein);
    
    // Teleport to player
    Location playerLoc = player.getLocation();
    npc.getEntity().teleport(playerLoc);
    
    // Drop items (use existing dismiss logic but don't destroy)
    dropInventoryItems(npc, player);
    
    player.sendMessage(ChatColor.GREEN + "Jarvis: Loot dropped! Resuming mining");
    
    // Restore state
    state.targetOre = pausedOre;
    state.currentVein = pausedVein;
}
```

## ⭐ **Feature 4: Danger Detection**

### Lava Detection
```java
private boolean isLavaNearby(Location loc, int radius) {
    for (int x = -radius; x <= radius; x++) {
        for (int y = -2; y <= 2; y++) {
            for (int z = -radius; z <= radius; z++) {
                Block b = loc.clone().add(x, y, z).getBlock();
                if (b.getType() == Material.LAVA) {
                    return true;
                }
            }
        }
    }
    return false;
}

// In mining loop:
if (isLavaNearby(npcLoc, 3)) {
    player.sendMessage(ChatColor.RED + "Jarvis: Lava detected nearby! Finding safer ore");
    state.targetOre = null; // Skip this ore
    state.currentVein.clear();
    return;
}
```

### Void/Fall Detection
```java
private boolean isVoidOrFallRisk(Location loc) {
    // Check for void
    if (loc.getY() < 5) {
        return true;
    }
    
    // Check for fall damage (no ground for 4+ blocks below)
    Location checkLoc = loc.clone();
    for (int i = 0; i < 5; i++) {
        checkLoc.subtract(0, 1, 0);
        if (checkLoc.getBlock().getType().isSolid()) {
            return false; // Found ground
        }
    }
    return true; // No ground found, fall risk
}
```

### Too Deep Check
```java
// In mining loop:
```

## 🎮 **Feature 7: Jarvis Battles (PvP)**

### Command
```
/jarvis battle <player>
```

### Implementation
```java
public void battle(Player player, Player target) {
    NPC myNpc = getNPC(player);
    NPC targetNpc = getNPC(target);
    
    if (myNpc == null || targetNpc == null) {
        player.sendMessage(ChatColor.RED + "Both players must have Jarvis summoned!");
        return;
    }
    
    // Stop current tasks
    stopTask(player);
    stopTask(target);
    
    // Start battle mode
    player.sendMessage(ChatColor.RED + "Jarvis: Engaging " + target.getName() + "'s Jarvis!");
    target.sendMessage(ChatColor.RED + "Jarvis: Under attack from " + player.getName() + "'s Jarvis!");
    
    // Set NPCs to attack each other
    BukkitRunnable battleTask = new BukkitRunnable() {
        @Override
        public void run() {
            if (!myNpc.isSpawned() || !targetNpc.isSpawned()) {
                cancel();
                return;
            }
            
            Entity myEntity = myNpc.getEntity();
            Entity targetEntity = targetNpc.getEntity();
            
            if (myEntity == null || targetEntity == null) {
                cancel();
                return;
            }
            
            double distance = myEntity.getLocation().distance(targetEntity.getLocation());
            
            if (distance > 50) {
                // Too far, end battle
                player.sendMessage(ChatColor.YELLOW + "Jarvis: Target too far, disengaging");
                cancel();
                return;
            }
            
            // Move toward target and attack
            myNpc.getNavigator().setTarget(targetEntity, true);
            
            // Deal damage when in range
            if (distance < 3 && myEntity instanceof Player && targetEntity instanceof Player) {
                Player myPlayer = (Player) myEntity;
                Player targetPlayer = (Player) targetEntity;
                targetPlayer.damage(2.0, myPlayer); // 1 heart damage
            }
        }
    };
    
    battleTask.runTaskTimer(plugin, 0L, 10L);
    activeTasks.put(player.getUniqueId(), battleTask);
}
```
